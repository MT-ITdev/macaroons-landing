# Macaroons — лендинг кондитерской

Одностраничный сайт-лендинг для кондитерской, продающей французские макаруны. Вёрстка адаптивная, стили собраны на LESS.

## Что реализовано

- анимированная секция-хиро с вращающимся кругом вокруг фото товара
- блок «о нас» с фактами о продукте (натуральные ингредиенты, более 70 вкусов, 10 лет на рынке)
- каталог вкусов с ценами и кнопками заказа
- форма оформления заказа с плавающей анимацией (клубника)
- футер со ссылкой на Instagram и контактным телефоном

## Стек

HTML, LESS/CSS, JavaScript
